# Hermes-Mail

Application OAuth **strictement personnelle** utilisée par le serveur maison de Nicolas Pires pour :

- la **sauvegarde chiffrée** (restic) vers Google Drive,
- l'envoi d'e-mails depuis le compte du propriétaire.

Cette application n'est pas destinée au grand public : seuls les comptes de son propriétaire l'utilisent.
